# 文档与文件约定

## 文档约定

- 简洁
- 认可署名：AI 对其认可并需要标记的内容，使用 `平台` 或 `平台 模型` 署名（如 `ChatGPT GPT-6`）。署名仅表示认可，不表示原创；应明确署名对应的内容范围。
- 删除内容时，同时清理围绕它形成的解释、否定、占位和未来暗示。**不要在 .git 外留下任何删除痕迹！！**

## 文件职责

- `README.md`：AI 工作台的定位与入口。
- `docs/`：由 AI 持续维护的讨论内容、研究、设计与决策文档。
- `rules/`：工作台参与者（包括 Agent）需要遵守的约定，主要由人类审视和微调。
- 临时内容遵守 [Draft 隔离](drafts.md)。
