# 文档与历史约定

- `README.md` 说明项目的研究重心——情绪化记忆库与时间感知，以及实验和基础设施的关系。
- `docs/` 记录当前研究模型、已形成的认识与参考资料；区分研究问题、尚待验证的假设和已有证据，不承担操作规范的职责。
- `rules/` 记录项目参与者（包括 Agent）需要遵守的操作约束。
- Demo 的当前实现说明及实验数据跟随相应 Demo；基础设施的实现和模块化架构文档由其所属仓库维护。
- 正式文档描述**当前有效的状态**，不维护普通实现变迁的叙述；代码修改和重构历史由 Git 记录。
- 具有长期比较价值的实验条件、原始结果和指标可以保留，但应注明对应代码版本、配置及测试条件。跨 Demo 的情绪化记忆与时间感知研究结论归入项目文档。
- 不得把调度、轮次计数或时间戳记录描述为已经验证的时间感知；也不得把尚未验证的情绪化记忆机制写成既有结果。
- 未整理的信息可放入 Draft；其命名与依赖边界必须遵守 [Draft 隔离规则](drafts.md)。
