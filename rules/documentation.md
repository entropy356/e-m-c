# 文档与文件约定

## 当前状态

- 正式文档描述**当前有效的**概念、机制、结论和使用方式；读者应能独立理解，不必追溯旧提交、聊天记录或 Draft。
- 内容变化时更新原文，清理过时和重复的描述。普通调参、重构与 Bug 修复由 Git 记录，无需另写变更流水账。
- 具有长期比较价值的实验条件、数据和结果按 [实验约定](experiments.md) 保存。

## 表述

- 简洁、清晰，减少不必要的负面表述。
- 区分已验证的结论、观察与尚待验证的判断；方向未确定时明确保留不确定性。

## 文件职责

- `README.md`：项目定位、组成与入口。
- `docs/`：研究模型、当前认识与参考资料。
- `rules/`：参与者（包括 Agent）需要遵循的约定。
- `demos/`：实验实现、使用说明与实验记录。
- 基础设施的架构和使用说明由所属仓库维护。
- 临时内容遵守 [Draft 隔离](drafts.md)。
