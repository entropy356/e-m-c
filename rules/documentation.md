# 文档与历史约定

- `README.md` 说明项目定位、组成和入口。
- `docs/` 记录当前研究模型、已形成的认识与参考资料；不承担操作规范的职责。
- `rules/` 记录项目参与者（包括 Agent）需要遵守的操作约束。
- Demo 的当前实现说明及实验数据跟随相应 Demo；基础设施的实现和架构文档由其所属仓库维护。
- 正式文档描述**当前有效的状态**，不维护普通实现变迁的叙述；代码修改和重构历史由 Git 记录。
- 具有长期比较价值的实验条件、原始结果和指标可以保留，但应注明对应代码版本、配置及测试条件。跨 Demo 的研究结论归入项目文档。
- 未整理的信息可放入 Draft；其命名与依赖边界必须遵守 [Draft 隔离规则](drafts.md)。
