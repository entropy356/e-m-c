# 研究协作约定

研究过程中的开放讨论、待办任务和长期知识分别使用 GitHub Discussions、Issues 和仓库文档承载。

- **Discussion：开放讨论。** 用于研究问题、方向探索、假设和不同观点；不要求一开始就形成明确任务。讨论逐渐收敛为具体工作时，创建 Issue 并相互链接。
- **Issue：具体工作。** 用于需要推进的分析、实验、调查或实现。说明要解决的问题及预期观察或交付结果即可；不要求固定模板。完成或决定暂不推进时，简要记录结果并关闭。
- **Docs：长期成果。** 将值得后续工作直接依赖的稳定结论、设计和决策整理到 `docs/`。只沉淀结论及必要依据，不复制整段讨论或任务过程。

不必为每个想法创建条目，也不必把讨论强行拆成任务。仓库尚未启用 Discussions 时，开放讨论暂时使用 Issue；启用后再按上述分工使用。
