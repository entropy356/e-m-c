# 元规则与设计依据

本文件集中记录只作用于规则自身的约定，以及各规则的设计依据。具体执行要求分别见 [文档规范](documentation.md)、[Draft 隔离](drafts.md) 和 [实验约定](experiments.md)。

## 规则自身的约定

- 规范按作用对象分文件，文件内部按规则性质分块。
- 规范本身也须遵守 [文档规范](documentation.md)，作为示例。

## 设计依据

### 文档

普通调参、重构、修复和方案迭代的过程已有 Git 记录。正式文档聚焦当前有效状态，使读者不必追溯旧提交、聊天记录或 Draft 才能理解当前内容。

### Draft

Draft 承担暂存笔记、实验材料和跨 Agent / 设备交换文件的职责，而非正式知识来源。严格隔离持久引用与依赖，使 Draft 不再需要时可以删除，且不影响边界外内容的独立理解、运行与验证。

### 实验

项目通过实验探索情绪化记忆库与时间感知的机制。Demo 围绕稳定的研究问题持续演化，算法、参数、模型和实现调整不必拆出新 Demo。

实验与基础设施相互促进：实验提出、检验共用能力的需求，基础设施提供可组合的运行环境。
