# 元规范

本文件记录元规范及其细化关系。其他规范见 [文档](documentation.md)、[Draft](drafts.md) 和 [实验](experiments.md)。

## 记法

```text
标识符:[被细化的规范1|被细化的规范2] = 规范内容
    - 意义1
    - 意义2
```

- 方括号内引用这条规范所细化的上层规范，不表示严格的逻辑推导；`|` 用于分隔多个上层规范。
- `[root]`：已确认的根规范，无上层规范。
- `[]`：暂不指定被细化的规范，不等于根规范。
- 缩进列表说明规范存在的实际意义；按需记录，不要求预先填写。
- 跨文件规范可以用 `[文件.md #章节](文件.md#章节):[被细化的规范]` 引用，不复制正文。
- 章节内的列表、表格和段落属于该章节的内部结构，不自动成为独立规范。

## 元规范

pragmatism:[root] = 规范遵循实用主义

agent-reader:[root] = 规范是给 Agent 读的

justifiable-value:[pragmatism] = 每条规范都应能在受到质疑时解释其存在价值
    - 使规范能够根据实际价值被评估、修改或删除。
    - 避免缺乏实际收益的规范长期积累。

minimize-negative-expression:[] = 减少不必要的负面表述
    - 减少无实际必要的限制。
    - 使规范更直接地表达期望行为。
