# Draft 严格隔离

Draft 用于暂存笔记、实验材料或跨 Agent / 设备交换文件。它可以存在任意时长，并遵守以下严格隔离约束。

## 命名与边界

**单个 Draft 文件使用 `x.draft.y` 命名，目录、Git 分支和仓库仍以 `.draft` 结尾。** `y` 是文件扩展名，放在末尾以保留编辑器和 GitHub 的文件类型识别。例如：

| 类型 | 名称示例 | 隔离范围 |
| --- | --- | --- |
| 文件 | `memory.draft.md` | 该文件 |
| 目录 | `research.draft/` | 目录及其全部内容 |
| Git 分支 | `review.draft` | 该分支的工作内容 |
| Git 仓库 | `prototype.draft` | 仓库内的全部内容 |

在一个 Draft 内部创建的文件属于该 Draft；嵌套的显式 Draft 对象另有自己的隔离边界。

## 必须遵守

对任意 Draft（包括 `x.draft.y` 文件及 `x.draft` 目录、Git 分支或仓库）：

1. **边界外的任何持久内容不得引用该 Draft 或其内部内容，包括其他 Draft。** 禁止文档链接、路径引用、import、脚本调用、配置、构建、测试、工作流和跨仓库引用；不得经由中间文件或生成物间接依赖它。
2. **边界外不得把该 Draft 的内容作为必要前提。** 不得要求读者查看 Draft 才能理解正式结论，也不得要求保留 Draft 才能运行、构建或验证外部内容。
3. **Draft 内部可以引用自身及边界外的非 Draft 内容**，但不能引用另一个独立的 Draft。嵌套 Draft 的外部内容也不得反向引用它。
4. **允许临时读取 Draft 并把成果复制、改写或整合到正式内容**；整合后的文件、测试和说明必须独立成立，不得留下指向该 Draft 的引用。
5. **不确定是否违反隔离时，默认禁止**，不要自行认定例外。

## 使用与清理

这里约束的是持久内容间的引用与依赖，不禁止为了整理成果而临时查看、检出或运行 Draft。普通 Git 提交祖先关系不视为分支引用。

Draft 无需自动清理、结束标记或定期删除；不再需要时可直接删除。临时分支或仓库只负责交换文件，不承担正式知识来源的角色。
