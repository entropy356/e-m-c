# 实验约定

## Demo 的演化

- **问题不变**：继续修改原 Demo。算法、参数、模型和实现调整由 Git 记录。
- **问题改变**：新建 Demo，使用稳定编号和简短主题名。
- **共用能力**：允许不同 Demo 暂时保留独立实现；共同需求逐渐稳定后，再考虑提取到基础设施。
- **基础设施归属**：基础设施的设计与实现由对应仓库维护。

## 验证与记录

记录观察、假设、测试条件和结果，并区分主观观察与对照实验结论。具体采用何种验证方式由研究问题决定。

以 [Demo 1](../demos/demo1-emotion-memory/README.md) 为例：

~~~text
demos/demo1-emotion-memory/
├── README.md       # 研究问题、当前机制与运行方式
├── emc/            # 实现
├── tests/          # 测试
├── experiments/    # 具有长期比较价值的实验记录
└── results/        # 原始数据与结构化指标
~~~

实验记录需注明关键条件、配置和代码版本，并指向相应数据。普通调参、Bug 修复和重构由 Git 记录。
