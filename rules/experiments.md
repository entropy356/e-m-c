# 实验约定

## Demo 演化

- **研究问题未变**：继续迭代原 Demo，算法、参数和实现变化由 Git 记录。
- **研究问题改变**：建立新 Demo，采用稳定编号和简短名称。
- 共用需求未稳定前，不同 Demo 可以保留独立实现；需要复用时再考虑提取基础设施。基础设施的设计与文档由所属仓库维护。

## 验证与记录

- 根据研究问题选择验证方法，区分观察、假设、主观评价与对照实验结论。
- 保留具有复核或长期比较价值的实验记录：关键条件、配置、代码版本（提交哈希）、结果及对应数据。
- Demo 的 README 说明当前研究问题、机制与运行方法。

参见 [Demo 1](../demos/demo1-emotion-memory/README.md)。
