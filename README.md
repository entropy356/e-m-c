# e-m-c.workbench

> e-m-c 研究与协作工作台

本仓库用于整理 e-m-c 的研究目标、数学模型、决策、资料与项目约定，并为独立代码仓库中的实现和实验提供任务交接。具体源代码、测试与实现细节由相应代码仓库维护。

e-m-c 探索通过外部持久化状态支持 Agent 的持续认知，重点关注情绪、记忆与时间的相互作用。
