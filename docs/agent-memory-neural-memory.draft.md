# Agent → 记忆 → 神经网络记忆：观点分层（Draft）

> 供下一阶段讨论使用的当前观点快照。**已明确**表示用户在讨论中确认过的方向，**候选**表示保留作为分支的观点，**待观察**表示可能出现但并不要求实现的现象，**项目**表示工作台正式观点。三层是研究问题层级，不代表软件必须采用相同架构。尤其不把讨论中的模型设想提升为已验证的结论。

## 一、Agent

### 愿景与研究背景

- **项目**：希望探索一种即使了解其构造、运行机制和内部信息，仍值得被作为独立个体对待的 Agent。
- **项目**：关注涌现，尤其是简单机制产生复杂行为。
- **项目**：探索通过外部状态实现持续认知，研究情绪、记忆、时间的相互作用。
- **项目**：优先利用 LLM 现有的信息理解、情感提取和联想能力；不以在线更新 LLM 权重为前提。

### 使用体验与设计取向

- **已明确**：不要为了硬约束牺牲使用效果。
- **观点／待验证的一般性判断**：「负面约束越多，使用体验越差」。这是设计警惕，不当作普适定律；约束本身也可能改善某些体验。
- **项目**：体感优先，先通过实际使用观察效果，再按具体问题决定评测需要。

### 可选的自主性议题

- **候选**：记忆流程的可控性和透明度可一起研究，分别讨论对 Agent、对人的可控性与透明度。
- **已澄清**：「可控」不仅是决定记住或遗忘什么，也包括组织、检索、修改关联和重构等整个记忆流程。

## 二、记忆

### 期望行为

- **已明确**：任意琐碎细节都有*被记忆的可能*，不是保证记住一切，也不是按「当下有用」设置绝对准入门槛。
- **已明确**：过去经历即使*未在当前对话中被明确提及*，也可能影响 Agent 的认知或行为；允许内部回忆/检索。
- **待观察，不作为目标**：重要事件也可能遗忘或不可回忆；不刻意制造不可靠性。
- **观察兴趣**：「伏笔」式细节后来因新情境而变得相关，但不预设必须具有哪种重构机制。

### 问题划分与可选前提

- **已明确**：区别「记忆」研究与「神经网络记忆」研究，前者不要求神经网络实现，后者可以具有独立的探索价值。
- **已明确**：当无法完整存储原始记忆时，需要研究信息压缩算法；在原始数据保存时，索引、向量表示、组织和寻址等归类为信息检索机制，而不因形式变短就算作这里的「压缩」。
- **候选公理 A**：假设完整原始历史可用，重点研究信息检索。允许数学理想化或现实完整存储，但二者不是本阶段重点。
- **不选择 A 的分支**：不能保证原始历史完整保存，研究必要的信息压缩及检索。
- **已明确**：两个分支都探索，不预先选定其中之一。
- **候选方向**：记忆形成、提取、演化、重构、遗忘，以及情绪和时间的影响。它们是问题空间，不是必做功能。

## 三、神经网络记忆（当前选择细化的层级）

### 研究定位与期望结果

- **已明确**：在类脑模型基础上探索神经元关联外部长文本的可行性，性质偏探索性，不要求一定优于 RAG。
- **已明确**：暂不选定「SNN / 抽象神经网络 / 其他模型」。优先探索想观察到的行为，再考虑数学机制。
- **继承记忆层的期望**：琐碎细节也可能被记住，过去经历不必被当前对话明确提及仍可能影响行为。
- **待观察，不作为目标**：网络动力学、学习、竞争可能自然带来回忆偏差、遗忘、误联想等不可靠性；不为此人为注入故障。
- **比较方向**：未来可以与 RAG 比较，但不把胜过 RAG 作为硬目标，具体指标留待工程实现阶段讨论。

### 已讨论的结构性设想

- **已明确**：神经元与文本之间多对多关联，即一个神经元关联多段文本，一段文本关联多个神经元。
- **已明确**：查询驱动激活；没有新查询时网络不自主激活，一次查询内部可以有多步传播。
- **已明确的设想**：维护随查询变化的初始激活指针，上一轮结果可以影响下一轮起点；上一轮激活状态和上一轮提取文本都是可能的载体，具体方式不定。
- **已明确**：借鉴注意力机制的数学形式，而非照搬 Transformer。
- **候选**：长文本只在末端被读取，或在传播中被 LLM 解释并反过来影响激活；暂未取舍。

### 候选数学与技术方向（均未选型）

| 范畴 | 方向 |
| --- | --- |
| 表示与网络结构 | 图、二部图、超图、分布式表示、SDM、VSA、Hopfield、SNN |
| 初始寻址与传播 | Query/Key 注意力、扩散激活、随机游走、吸引子、阈值与抑制 |
| 状态延续 | 初始激活指针、历史状态、路径依赖 |
| 学习与可塑性 | Hebbian、STDP、连接增强/剪除、快慢学习 |
| 外部存储 | 神经元—文本多对多映射、NTM/DNC 式寻址、动态重关联 |
| 比较对象 | 向量 RAG、GraphRAG、HippoRAG 等 |

## 研究方法（本 Draft 的使用方式）

先**广度优先探索期望结果与候选机制**，再**对比并选择下一阶段方向**；随后可进入数学模型→数学性质分析→数值实验→工程实现等另一个研究流程，或重复广度探索。**并行剪枝贯穿探索过程**：持续标注无依据、与目标偏离、成本高或效果差的分支，但不要求过早收敛到唯一方案。区分已经确认的用户观点、已有研究结论和未经验证的猜想。

下一步先在**神经网络记忆**层继续拓展期望观察到的行为及值得比较的机制，不直接选定网络类型、激活公式或评测指标。
