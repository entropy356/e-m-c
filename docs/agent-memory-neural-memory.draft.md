# Agent → 记忆 → 神经网络记忆：研究目标与开放前提（Draft）

> 当前讨论的目标与分歧。**确认**表示用户已表明的意图；**候选**表示尚未取舍的方向；**观察**不等于优化目标。三层是问题层级，不是实现架构。正式项目定位以 [决策与观点清单](decisions-and-views.md) 为准。

## Agent：期望与设计取向

- **确认**：重视使用体验；不要为了无必要的硬约束牺牲效果。
- **候选判断**：「负面约束越多，使用体验越差」。不将其视为普遍规律，具体约束是否必要仍需观察。
- **候选议题**：「记忆流程的可控性」与「透明度」宜一起讨论，分别考虑对 Agent、对人的维度。可控性涵盖记忆形成、组织、检索、关系修改和重构，不局限于主动记住/忘记。
- **研究取向**：优先问期望结果和体验，不要求用户在缺少实际长期记忆 Agent 使用经验时，先对照 RAG 作出偏好判断。

## 记忆：与神经网络实现相区分

### 确认的期望

- **任意琐碎细节都有被记忆的可能**；并非保证保存或回忆一切，也不以「目前有用」作为绝对写入门槛。
- **过去的经历即使未被当前对话明确提及，也可能影响 Agent 的认知与行为**。不排斥 Agent 内部进行记忆检索。
- 对后来才显现意义的「伏笔」细节保持关注，但其形成、重解释或回忆机制尚未确定。
- **观察而非目标**：遗忘重要事件、提取偏差、错误联想等不可靠性可以自然出现，但不为了模拟不可靠而刻意制造错误。

### 候选前提与问题划分

- **确认**：「记忆」和「神经网络记忆」是两个可分别成立的研究目标，不以神经网络为一般记忆研究的必要条件。
- **确认的分类**：若无法完整保存原始记忆，才需要研究信息压缩；为检索建立索引、向量、图或其他辅助表示，即使形式更短，也视为检索机制而非这里所说的压缩。
- **候选公理**：假定完整原始历史可用；探索该前提成立时的检索机制，也探索不选它、需要处理有限存储及压缩的分支。不必现在决定采用哪个分支。

## 神经网络记忆：当前探索焦点

### 已明确的设想

- 研究在类脑模型基础上让神经元与外部长文本形成**多对多关联**：每个神经元可关联多段文本，每段文本可关联多个神经元。
- **查询驱动激活**：没有查询时不自主激活；一次查询内可有多轮传播。
- 初始激活位置或分布可随查询移动；例如上一轮的神经元激活结果或提取文本成为下一轮起点的线索。**如何更新尚未确定**。
- 可以借鉴注意力机制的**数学形式**，不预设照搬 Transformer。
- 具体类脑模型（如 Hopfield、SNN、抽象神经网络等）尚未选择；关联文本是仅在读取时参与，还是在传播中参与，也未选择。

### 研究边界

- **探索性研究**：不以必然优于 RAG 为硬要求；RAG 可作为未来对照，评测指标待工程实现阶段再议。
- **先结果后机制、广度优先**：此阶段收集与比较可能观察到的行为，保留分支，不因每出现一个候选机制就立即深入选型。
