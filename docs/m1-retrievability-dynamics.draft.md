# M1：完整存储下的可提取性演化（独立研究 Draft）

> 本文只研究：**不额外添加“存储强度 / 提取强度”变量，M1 现有结构能自然出现什么，不能出现什么？** 这是独立研究记录，不修改 M1 公式，不是正式架构决策。实验均使用合成向量或小型精确图，不能外推至真实 Agent。

## 结论

1. **存储与提取分离已经成立**：旧原文未变，而新内容写入、当前查询、跨轮指针可改变其检索得分与排序；无须额外“提取强度”变量。
2. **增长不等于单向遗忘**：同一查询下，新增文本有时降低、有时提高既存文本的检索分数。这种现象不只存在于神经元网络，也出现在普通文档图。
3. **移动指针不等于长期学习**：M1 默认历史系数上限仅为 0.16，固定网络下，两个不同历史指针的影响对连续后续查询以几何速率衰减；有些明确查询甚至直接使历史影响归零。
4. **回忆不永久学习**：检索只改会话指针，不改神经元关系；没有查询或写入，现实时间本身不引起演化。
5. **另一个重要风险**：词法与向量检索都没有证据时，即使原文完整保存，仍可能完全找不到它。

## 一、如何定义“可提取性”

这里不虚构一个神秘的提取强度。对同一个存储片段 j，把同一查询下的最终得分、排名、是否进入 Top-K 作为观测量。区分：

- **新增文本引起的改变**：旧原文和查询保持不变，写入改变关联矩阵及图；
- **跨轮指针引起的改变**：数据及当前查询不变，之前的查询历史不同；
- **当前查询引起的改变**：数据及图不变，查询线索改变。

这三种机制应该分别测试，不能一律称为“遗忘”。

## 二、数学推导：跨轮历史为什么会迅速淡化

M1 使用神经元—文本列随机关联矩阵 B，经历邻接 A，神经元边权 W 和列随机转移 T。给定直接检索分布 d、读取矩阵 R、重启参数 α、神经元读取混合权 β，定义

$$
W=BB^\top+\eta BAB^\top,\quad
T=W\operatorname{diag}(W^\top\mathbf1)^{-1},
$$

$$
P_T=\alpha[I-(1-\alpha)T]^{-1},\qquad
s_t=Bd_t,
$$

$$
p_t=P_T\big[(1-\gamma_t)s_t+\gamma_t p_{t-1}\big],
\qquad
z_t=(1-\beta)d_t+\beta Rp_t.
$$

**为什么这样建模？** B 保留多对多寻址，W 表达文本共享与显式经历邻接，T 使传播质量守恒，P_T 是可证明收敛的带重启扩散，p 是随查询移动的历史起点；读取分数 z 将直接命中与网络检索合并。这些是设计选择，不是唯一的记忆理论。

因为 T 非负列随机，P_T 也非负列随机。对两个**数据库固定且后续查询完全相同**、只在起始 p 不同的会话，设差值 δp，则

$$
\delta p_t=\gamma_tP_T\delta p_{t-1}.
$$

取 M1 的 $0\le\gamma_t\le\rho=0.16$，利用列随机矩阵对一范数非扩张的性质，有

$$
\|\delta p_t\|_1\le\rho^t\|\delta p_0\|_1,\qquad
\|\delta z_t\|_1\le\beta\rho^t\|\delta p_0\|_1.
$$

三次有效查询后，历史差异的上界缩小为原来的 0.4096%；五次后为 0.01048576%。若某次 γ=0，则两个不同会话状态当轮合并。**无查询则不更新 p**，所以这里是按有效查询次数衰减，不是按现实时间衰减。此证明限制的是分数差异，不能保证 Top-K 排名不发生跳变。

## 三、数值实验与反例

以下是用此前 M1 参考实现、NumPy/SciPy 运行的新实验。精确小图直接解线性方程；其他实验是预先选定的简化数据与参数。

### 3.1 旧记忆并非只会越来越难提取

取 B=I（M1 的合法特例，即普通文档图），α=0.27、β=0.43、η=5；查询只直接命中 A：

| 经历图 | B 得分 | C 得分 |
| --- | ---: | ---: |
| A—B | 0.175953 | — |
| A—B—C | 0.169642 | 0.064088 |
| A—B—C—D | 0.146901 | **0.069257** |

新增记忆后旧 B 变弱，但**旧 C 在新增 D 后反而变强**。所以单纯的“新记忆稀释旧记忆”不是通用数学定理。该结果是图的流量重新分配，而不是新增了遗忘变量。

### 3.2 500 个随机种子的增量写入对照

原有 18 个文本块，每 3 块属于同一经历；查询始终只命中第 0 块。新增第 19 块，观察原经历中间位置（第 6 块）与原链尾（第 12 块）。唯一词查询、零查询向量确保新增前后**直接检索分布 d 完全相同**。下表为 M1 默认多对多绑定 r=3 时的得分变化中位数：

| 新块写入方式 | 旧中间块 | 旧链尾块 |
| --- | ---: | ---: |
| 新经历，随机语义向量 | -0.0000156 | -0.0000125 |
| 同一经历，随机向量 | **-0.008251** | **+0.003179** |
| 同一经历，靠近旧向量 | -0.011386 | +0.006303 |

每行 500 种子；这里指定的目标位置上各次方向一致，**不代表任意图都遵循相同方向**。在“同一经历、随机向量”下，旧链尾块有 6/500 次从 Top-5 之外进入 Top-5；大多数分数变化没有改变 Top-K 成员身份。

**公平对照**：设 r=1，便有 B=I，也就是普通文本图版本。新增同组文本后，中间旧块下降 0.022742，旧链尾块上升 0.005169；新增完全独立经历时旧得分保持不变。这证明主要正负变化由图结构即可解释，不是神经元层的独有贡献。

### 3.3 多对多绑定还有额外竞争，但未必是好处

如果不同经历中新文本的嵌入恰好等于旧 A 文本嵌入，M1 可以把新文本的部分质量关联到旧 A 神经元。一个两旧一新的精确例子中，旧 A 神经元读回 A 的份额从 1 降至 0.90909；固定精确查询 A 的总分从 1.00000 降至约 0.90293。原文没有删除。

与 B=I 时互不影响的独立经历相比，这是多对多绑定的特殊机制；但它也可能造成**无关经历对明确记忆的干扰**。

### 3.4 指针是短暂路径依赖

30 条合成文本都有共同词 common 和独立标记。两个会话先分别检索不同唯一标记，再对完全相同的 common 连续查询，γ 每轮均为 0.16。

| 同一模糊查询重复次数 | 神经元激活差异 L1 | 最终检索分数差异 L1 |
| --- | ---: | ---: |
| 1 | 0.222652 | 0.091681 |
| 2 | 0.030065 | 0.012397 |
| 3 | 0.004056 | 0.001677 |
| 5 | 0.0000738 | 0.0000306 |
| 7 | 0.00000135 | 0.00000056 |

第一轮，同一旧片段在两会话中的排名为第 5 与第 9；第三轮均为第 8。说明历史状态可以短期改变 Top-K，但会较快消散。

**更强的反面证据**：复核此前合成关联任务中的 80 条明确查询，默认门控得到 **80/80 次 γ=0**。因此早期“打开历史指针但 Recall 不变”**并不能证明指针有益**：在这些查询上，它完全没有参与计算。

### 3.5 原文完整保留，也可能找不到

参考实现的分词器不覆盖所有 Unicode 符号。只存储文本“🎈🧩”、同时嵌入为零向量，则即使用相同字符串查询也没有词法或向量证据，不能通过普通检索返回；这与“任意琐碎细节都有被记忆的可能”的期望存在值得修复的边界情况。

现有参考代码对这种情况抛出 LookupError，而 M1 数学规格描述“返回空结果”，也存在 API 不一致。可以优先尝试最简的原文精确匹配/Unicode 兜底，**不必因此发明新的记忆强度变量**。

## 四、分类总结和暂用剪枝

| 目标 | 当前 M1 是否能做到 |
| --- | --- |
| 原文不变，因新文本写入而改变提取分数 | **能**，可能升高或降低 |
| 同一查询，因不同历史而短暂返回不同结果 | **能**，但默认历史很弱、门控常归零 |
| 回忆成功后永久改变关联 | **不能**，查询不改 B/W/T |
| 只因现实时间流逝改变可提取性 | **不能**，时间戳未进入模型动态 |
| 普通图检索完全不能模拟上述变化 | **不成立**，多个关键现象已有普通图对照 |
| 任意原文都必然能通过检索触达 | **不能保证**，存在无证据反例 |

**下一阶段不建议先增加独立的提取强度、随机遗忘或回忆强化变量。** 优先在真实短对话上对照：直接混合检索、带相同关联元数据的文档图检索、M1；分别观察历史偏向是否有用、关联是否错误、细节能否被检索，以及 LLM 是否真正正确使用记忆。只有确实需要回忆后长期学习时，再研究可塑性机制。

## 五、证据与复现

- **数学上可证明**：历史指针一范数收缩上界、B=I 的文档图退化特例、固定图在无事件时不演化。
- **数值观察**：小型链图精确解、同种子增量写入、两会话历史比较、绑定竞争与零证据反例。
- **没有验证**：真实自然语言 Embedding、长时间部署、Agent 回答质量、情绪调制、人与 Agent 的体验。
- 本次实验基于原有 M1 NumPy/SciPy 参考代码，新增增长对照、历史对照、性质断言与结果 JSON。实验附件可独立运行；本文件仅保存研究结论，不把一次合成观察提升为正式架构决策。
