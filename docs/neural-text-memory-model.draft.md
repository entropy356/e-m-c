# 查询驱动的神经元—长文本记忆：M1 数学模型与数值实验（Draft）

> **研究产物，不是正式架构决策。** 第一轮自主深度优先研究，目标是得到可计算、能无歧义转成记忆库的最小模型，并在实验中主动寻找失败条件。采用「完整原始历史可用」这一**本轮暂用前提**，不代表所有未来路线都采用它。以下数值结果来自合成数据与小规模人工短句，**不是生产性能证明**。

## 0. 研究判断与剪枝

- **保留 M1**：查询驱动的稀疏神经元网络、原文存储、多对多关联、带重启的扩散激活、可移动跨轮指针；网络状态有唯一解，且写入与查询均可实现。
- **本轮不引入**：SNN 脉冲时序、Hopfield 能量函数、在线梯度训练、每一传播步的 LLM 调用、基于回忆自动强化边。这些机制不是不可能，而是在当前目标下缺少必要性或可能引入难解释的反馈。
- **核心负面结果**：对有可靠经历相邻关系的检索任务，简单的**文档相邻展开 / 文档图 PPR**可达到或超过 M1；目前**没有证明神经元层带来独有的检索收益**。该结果必须作为下一阶段是否保留神经元层的剪枝依据。
- **已知失败条件**：错误关联边、无可检索线索、长链条、多义查询与状态偏置、外部 Embedding 失真。任何琐碎细节可以写入，但无法保证每次都能回忆。

## 1. 研究目标和定位

期望满足：（1）不按当下重要性设置硬写入门槛，琐碎细节也能留在可访问历史中；（2）当下没有明确提起旧经历，记忆仍可能通过内部检索影响回答；（3）查询驱动，静默期无需自主激活；（4）神经元与文本多对多关联；（5）可存储跨轮初始激活指针。遗忘与误联想仅是观察现象，**不作为优化目标**。

**区分三件事**：原文是否保存、信息是否可找到、Agent 是否正确使用信息。M1只规定前两者的一种可实现机制，回答质量还取决于调用它的 LLM。它是**借鉴神经计算的线性递归激活网络**，不等于生物神经元模型。

## 2. 基本对象和工程契约

### 2.1 原文、分块与编码器

- 原始文档 \(D_i=(\mathrm{id},\mathrm{raw},\mathrm{time},\mathrm{episode\_id})\)；raw 原样保存，ID 唯一持久。每个非空文档按 Unicode 码点划成 600 码点窗口，重叠 80，步长 520；末块允许不足 600。每个块保留 chunk_id、doc_id、start、end、text，原始长文本不因建索引而丢失。
- 记块数为 \(m\)。M1 为每个块建立一个主要神经元地址，所以 \(n=m\)，但**神经元与文本的关联不是一对一**：下面的 \(B\) 可以有多对多非零项。
- 外部编码器 \(E:\mathrm{text}\to\mathbb R^d\) 需固定名称、版本、维度；保存写入时的嵌入。非零编码单位化，零编码保留为零。M1 不假设编码器能理解所有细节。
- episode_id 由调用方明确提供；没有提供时默认 doc_id。不能仅凭语言模型的猜测生成跨文档的“可靠关联”。

### 2.2 多对多关联矩阵

第 \(j\) 个块建立神经元 \(u_j=\widehat{E(c_j)}\)。从此前 \(i<j\) 的神经元中，选择与其余弦相似度严格为正的前 \(r-1\) 个（\(r=3\)），按相似度降序、同分按更小 ID 排序，记为 \(S_j\)。当前块自身的神经元始终被纳入。

取保留参数 \(\kappa=0.9\)。若 \(S_j=\varnothing\)，设置 \(B_{jj}=1\)，其他 \(B_{ij}=0\)。否则：

\[
B_{jj}=\kappa,\qquad
B_{ij}=(1-\kappa)\frac{\max(0,u_i^\top u_j)}
{\sum_{h\in S_j}\max(0,u_h^\top u_j)}\quad(i\in S_j).
\]

其他项为零。由此 \(B\in\mathbb R_{\ge0}^{n\times m}\)，每列之和为 1。旧关联列永不因新写入而修改。一个神经元可以被多个后续文本关联，每个文本也可能有多个神经元。

**为什么设高自身权重？** 若各近邻均分激活，当前线索会大量泄漏给近似文本；保留自身地址有利于明确定位原始片段。这是计算上的候选简化，不是生物假设。

### 2.3 神经元传播关系

定义文本块的无向邻接 \(A\in\{0,1\}^{m\times m}\)：同一 episode_id 内按写入顺序相邻的两块，令 \(A_{jk}=A_{kj}=1\)，其余为零。取关系参数 \(\eta=5\)：

\[
W=BB^\top+\eta BAB^\top,\qquad
T=W\operatorname{diag}(W^\top\mathbf1)^{-1}.
\]

\(W\) 是非负对称神经元关系矩阵，\(T\) 是**列随机**转移矩阵。\(BB^\top\) 表示共同绑定，\(BAB^\top\) 表示来自可靠经历邻接的传播。由于每个神经元都有对应块上的正自身关联，\(W\) 每列和严格为正。

**增量写入**：新块关联列记为 \(b_j\)。旧 \(W\) 补零升维后增加 \(b_jb_j^\top\)；若新块与同经历前驱 \(k\) 相邻，额外增加 \(\eta(b_kb_j^\top+b_jb_k^\top)\)。旧 \(B\) 列不动。故可以局部更新稀疏图，不必为了写入而重新训练神经网络。

### 2.4 查询、初始指针与停止条件

输入查询 \(q_t\) 与 \(\widehat{E(q_t)}\)。直接检索 \(d\in\mathbb R_{\ge0}^m\) 既构成 RAG 基线，又给神经元提供初始激活。

1. **词法**：BM25，\(k_1=1.2,b=0.75\)，\(\mathrm{IDF}(w)=\ln[1+(m-\mathrm{df}(w)+0.5)/(\mathrm{df}(w)+0.5)]\)，标准 BM25 TF 项为 \(\mathrm{tf}(k_1+1)/[\mathrm{tf}+k_1(1-b+b\,\mathrm{len}/\overline{\mathrm{len}})]\)。查询词去重。分词：NFKC + casefold；ASCII 单词/数字/下划线；汉字连续段的单字和相邻双字词。
2. **语义**：\(e_j=[\max(0,\widehat{E(q_t)}^\top u_j)]^5\)，零嵌入贡献 0。
3. 两路分别选严格正得分的前 \(L=15\) 个，各自归一化为和 1，平分时按块 ID 升序。若两路都有证据，\(d=\theta d_{\rm lex}+(1-\theta)d_{\rm sem}\)，\(\theta=0.65\)。只有一路有证据则用该路；两路均无证据则返回空列表，**不修改历史状态**。
4. 神经元直接种子 \(s=Bd\)。上一轮收敛分布 \(p_{t-1}\) 是历史指针；首次查询历史为空。
5. 令 \(d_{(1)}\ge d_{(2)}\) 为直接分布最高的两项（缺项补 0），\(\rho=0.16,\tau=0.15\)，定义歧义门控：

\[
\gamma_t=
\begin{cases}
0,&\text{历史为空},\\
\rho\max[0,1-(d_{(1)}-d_{(2)})/\tau],&\text{其他情况}.
\end{cases}
\]

\[
v_t=(1-\gamma_t)s+\gamma_t p_{t-1}.
\]

高置信的当前查询弱化历史，模糊查询允许历史偏向。这个门控是**经验性候选规则**，不是已证明的最优策略。新块写入时将旧 \(p\) 末尾补零；删除重建索引时重置 \(p\)。

6. 取 \(\alpha=0.27\)，初始化 \(a^{(0)}=v_t\)，执行：

\[
a^{(k+1)}=\alpha v_t+(1-\alpha)T a^{(k)}.
\]

当 \(\|a^{(k+1)}-a^{(k)}\|_1\le10^{-9}\) 停止，正常数值情况下默认参数最多 100 步足够。完成查询后 \(p_t=a_t\)，无查询时无自主激活。

7. 从神经元取回文本：定义

\[
R_{ji}=\frac{B_{ij}}{\sum_{\ell=1}^{m}B_{i\ell}},\qquad
h=Ra_t,\qquad
z=(1-\beta)d+\beta h,\quad\beta=0.43.
\]

\(R\) 列和为 1，\(h,z\) 为非负且总和为 1。按 \(z\) 降序取前 \(K=5\)，同分按块 ID 升序；返回块文本、原文位置及 direct/neural/total 三种分数。下游 LLM 再决定如何在上下文预算内读取原文。

## 3. 数学性质与边界（可证明）

1. **原始存储与提取分离**：在完整原文保存的本轮前提下，索引不丢弃原文；但这不蕴含每条记忆都能被任意查询找到。
2. **概率约束**：\(B,T,R\) 都是非负列随机矩阵；\(d,s,v,a,h,z\) 都属于概率单纯形（忽略浮点误差）。
3. **唯一收敛**：\(F(a)=\alpha v+(1-\alpha)Ta\) 对 \(\ell_1\) 距离是系数 \(1-\alpha<1\) 的压缩映射，有唯一不动点
   \[
   a^\star=\alpha[I-(1-\alpha)T]^{-1}v.
   \]
   从 \(a^{(0)}=v\) 开始，\(\|a^{(k)}-a^\star\|_1\le2(1-\alpha)^k\)；因此 \(\alpha=0.27\) 时 100 步的理论上界远小于 \(10^{-9}\)。
4. **可审计的残差**：若 \(\|a^{(k+1)}-a^{(k)}\|_1=\epsilon\)，则距不动点不超过 \(\epsilon/\alpha\)。
5. **路径衰减**：走过 \(k\) 条边的贡献受到 \((1-\alpha)^k\) 和边的转移概率乘积抑制，长关联链可能排不进小 \(K\)。
6. **必要的反例检验**：乱配经历关联边应损害依赖这些边的任务；没有查询词和向量证据时不能强行宣称找到记忆。
7. **精确退化情形**：如果令 \(B=I\)，则 \(R=I,W=I+\eta A\)，M1 便成为**直接在文本块图上执行的 PPR**。当前 \(\kappa=0.9\)，所以 M1 接近这类普通文档图检索。**神经元层的独特价值尚未得到证明**，不能仅凭类似图检索的成绩声称神经科学上的新发现。

上述定理只涉及此有限维计算系统，不保证 Agent 的长期行为、语义理解或类似人脑的性质。

## 4. 数值实验（可复现，但仅为机制检验）

**任务构造**：每个合成经历包含一个可被直接查询定位的 A 块，以及语义向量独立、不能靠普通相似度识别的 B 块，二者有显式经历邻接。加入同主题干扰块，查询只给 A 的线索，以 B 是否进入前 5 为结果。默认每种随机种子含 80 组经历与 80 个干扰块，共 240 块；比较 5 个随机种子（400 次关联查询），灵敏度/破坏性测试比较 3 个随机种子（240 次）。向量为 48 维**合成向量**，不是现实 Embedding。评测指标仅用于当前实验发现错误，**不是项目最终评测指标**。

### 4.1 消融（400 次）

| 模型 | 关联目标 Recall@5 | 精确稀有词检索 Recall@5 |
| --- | ---: | ---: |
| 直接词法 + 向量检索 | 0.75% | 100% |
| 有神经元—文本关联，但不扩散 | 1.50% | 100% |
| 有扩散，无经历关联边 | 1.50% | 100% |
| 完整 M1（不使用历史） | **100%** | 100% |
| 完整 M1 + 默认歧义门控历史 | **100%** | 100% |

稀有词测试极容易：查询明确包含目标块的独有词，且测试向量也接近目标，因此 100% **不能当成真实细节检索性能保证**。

### 4.2 与更简单的强基线（每组 5 个种子）

| 需要到达的目标 | 直接检索 | 直接命中后展开相邻文本 | 文档图 PPR | M1 |
| --- | ---: | ---: | ---: | ---: |
| 经历链第 2 块，Recall@5 | 0.75% | **100%** | **100%** | **100%** |
| 经历链第 3 块，Recall@5 | 0.50% | 0.50% | **100%** | 96.25% |

**解释**：关联边本身贡献了主要信息；在此构造上神经元网络没有证明比直接文档图更有效。不能使用相同的关联元数据、却只与不具备这些元数据的最弱 RAG 基线比较后宣称神经元优势。

### 4.3 失败与敏感性（每点 3 个种子）

- **错误经历边**：关联标识随机错配 0%、20%、50%、100% 时，Recall@5 分别约为 **100%、81.67%、51.67%、2.50%**。它的联想能力同样可以成为误联想来源。
- **更长链条**：目标在第 2、3、4 块时，Recall@5 约为 **100%、96.25%、15.42%**；默认参数下四块长链显著失败。
- **重启概率**：α = 0.15、0.27、0.4 的第 4 块 Recall@5 约 **43.75%、15.42%、0.42%**。降低 α 可加强多步传播，但需要更多迭代，并可能加重无关传播；α = 0.08 的扫描触及 100 步上限，不能视为完全收敛结果。
- **样本规模**：20、80、200 组经历 + 等量干扰时，第 2 块 Recall@5 均为 100%；这只覆盖约 60 至 600 块的简单合成任务，不支持大规模性能外推。
- **指针的作用**：在「前轮明确提示某经历，后轮只模糊地问通用词」的特殊任务中，取 β = 0.8、ρ = 0.4，无历史目标 Top10 命中 0%，歧义门控历史约 **98.33%**；而默认 β = 0.43、ρ = 0.16 下同类任务并无 Top10 命中，只有平均名次改善。故默认的跨轮状态**尚未证明具有显著实用收益**。
- **陌生话题切换**：在强线索的简单测试里，有无历史都能保持目标 Top1=100%，这不是更困难主题切换的充分证据。
- **中文短句烟雾测试**：54 个手写短句、12 对明确相邻经历，用字符哈希而非真实语言向量；直接检索目标 Recall@7 为 **1/12**，M1 为 **11/12**。数据小且专门构造，不得宣称真实中文记忆质量。

## 5. 工程接口与无歧义实现顺序

建议库界面：

```text
MemoryStore(encoder_id, encoder_version, dimension, fixed_parameters)
append(doc_id, raw_text, timestamp, episode_id=None) -> chunk_ids
retrieve(query, session_id, k=5) -> ranked chunks, activation metadata
reset_session(session_id)
get_raw(doc_id) -> original text
delete(doc_id) -> rebuild index, reset affected activation pointers
```

- 原文和元数据是**事实来源**；所有嵌入、`B/W/T/R`、BM25 倒排索引是可重建的派生数据。持久化版本与参数以保证重建一致；单一 `session_id` 的 p 不应意外写入其他会话。
- `append`：原文落盘 → 按固定规则产生块 → 使用同版本 E 编码 → 对每块创建自身神经元和少量历史邻近连接 → 更新 B、W、BM25 与索引统计 → 旧 p 补零。写入与索引应有事务/可恢复性，避免只保存了文本却对外宣称检索索引已完成。
- `retrieve`：从当前快照创建 d、s、v → 在固定 T 上迭代 → 读取和排序文本 → **在成功检索后**更新同会话 p。无证据直接返回空数组并不更新状态；查询中不修改记忆连接。
- 多个写入与查询并发时，检索使用一致索引版本；相同会话的状态更新需要串行化或版本比较，以避免覆盖较新的 p。
- 全量重建时按原始写入顺序重放，以保证「仅关联以前已有的神经元」得到相同 B；删除后重新排序会改变神经元 ID，因此清空历史 p。相同分数按较小 ID 排序。
- 性能：每次块写入朴素近邻计算 O(nd)，可换成近似近邻索引；形成稀疏边的局部更新约 O(r²)。每次查询的扩散成本 O(I·|E_W|)，其中 I 是迭代次数；总存储包括完整原文、向量、稀疏关联矩阵和会话状态。前期可以用 SQLite/普通向量接口与稀疏矩阵实现，不要求训练一个额外模型。
- **不要把该库的「有检索结果」误报成「回答有可靠证据」**；保留原始来源、chunk 位置及分数供调用方使用。后续真实 Agent 的上下文预算、回答校验和隐私控制仍须独立工程验证。

### 建议立即进行的工程验收

1. 相同原文、同版本编码器、同写入顺序，重建后排名与数值容差内一致；
2. 长文本任意位置的词法线索有被索引的机会，不因「不重要」被拒绝写入；
3. 关闭关联扩散时退化为直接检索；关闭经历边时关联命中应相应改变；
4. 无查询不更新 p；无检索证据返回空；跨会话状态隔离；
5. 构造错误关系与连续主题切换的失败测试；与有相同关联元数据的文档图检索公平对照。

## 6. 下一阶段决策建议

**M1 已达到可无歧义工程实现的数学定义阶段；尚未达到有真实 Agent 使用证据的生产选型阶段。**

若目标是尽快拥有好用的记忆库，最小工程路线应先实现「原文保留 + 混合直接检索 + 可靠经历邻接展开」，因为当前实验证明它已经能实现示例收益。M1 的神经元网络层可作为**可开关的对照实验模块**；只有在真实语料中发现传统邻接展开无法表达的路径依赖、分布式关联或动态行为，并观察到明确好处时，再考虑把它变成默认路径。

此选择符合奥卡姆剃刀和可证伪性：不要仅因为神经动力学有趣就强制引入实体，也不要仅因为模型能运行就断言它能产生希望的 Agent 行为。
